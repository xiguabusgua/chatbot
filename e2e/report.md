## 按天记忆（YYYY-MM-DD.md）

入口：数据管理 → 按天记忆。

### 写入
- 每轮问答结束后，把「用户提问 + 助手回复」追加到当天的 md 文件，格式：

```md
# 2026-11-17 对话记忆

## 10:34 · 用户
上次报的多少钱来着

## 10:34 · 助手
好的，我记得上次的价格。
```

- 助手回复通过 `res.clone()` 旁路读取 SSE，流结束后落盘，不影响正常渲染。

### 读取（跨天续记）
- 启动时读取**今天之前**的记忆文件，按日期从近到远（默认最近 3 天，可选 1/3/5/7）。
- 总预算 4000 字符，超出截断；拼成 `【此前几天的对话记忆】` 段落追加到请求的 `system`。
- 页面跨天不关闭时，每分钟 / 回到前台检查日期并重新换档。

### 存储
| 模式 | 说明 |
|---|---|
| 文件夹（Chromium） | File System Access API，直接读写真实 `YYYY-MM-DD.md`；目录句柄存 IndexedDB，重启后可能需要重新授权 |
| 浏览器本地（兜底） | 同样的 md 文本存 localStorage，可单日导出 `.md` |

### 验证（`node e2e/daily-check.mjs`，10/10）
跨天注入（昨日+前日按序进入 system）、当天落盘含用户与助手原文、日期列表、原文预览、导出 `.md`、关闭记录后不再写入、重新开启恢复。

## 新建对话选角色 + 记忆按角色隔离

### 交互
- 点击「开启新对话」时弹出角色选择（不使用角色 / 各角色卡），选择后自动触发应用原生的新对话。
- 没有角色卡时不弹面板，保持原生行为。
- 角色卡页「取消使用角色」会同时解绑所有绑定到该角色的会话。

### 绑定方式
应用未暴露会话 id（请求体、请求头、localStorage 均无），因此用**首条用户消息**归一化后取短哈希作为对话指纹：
- 该对话首次发消息时，把「新对话选择」写入 `chat-demo:conv-char`（指纹 → 角色 id）；
- 后续请求按指纹命中，回旧对话也能恢复原角色；
- 未走过选择器的对话回落到全局「设为当前角色」。

### 记忆
- memory 仍按角色存 `chat-demo:memory:<角色id>`，与单次对话无关；同一角色跨对话共享、不同角色互不可见。
- 自动记录（若开启）写入的是**本轮绑定角色**的记忆，不会串到别的角色。

### 验证（`node e2e/card-bind-check.mjs`，10/10）
选角色注入、隔离、回旧对话恢复、绑定持久化、新增记忆生效、不使用角色。

七套回归合计：23 + 12 + 8 + 8 + 10 + 10 + 10 = **81 项全通过**。
